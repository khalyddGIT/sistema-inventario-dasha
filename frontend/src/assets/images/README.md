# Carpeta de Assets & Imágenes Estáticas

Guarda en esta carpeta todas las imágenes estáticas del sistema:
- Logo de la Botica (`logo.png`)
- Iconos e ilustraciones (`assets/images/illustrations/`)
- Banners o marcas de agua

## Uso en plantillas HTML de Angular:
```html
<img src="assets/images/logo.png" alt="Logo Botica DASHA" />
```

## Uso en archivos de estilos CSS:
```css
.hero-banner {
  background-image: url('/assets/images/banner.jpg');
}
```
